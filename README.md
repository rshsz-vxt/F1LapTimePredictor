# F1LapTimePredictor
A Machine Learning project predicting F1 lap times by analyzing tire degradation.

Formula 1 Lap Time Prediction & Tire Degradation Analysis
This repository contains a data science project that models physical tire wear in Formula 1 racing. Using real-world race data from the 2019 Italian Grand Prix, this project engineers a custom 'Tire Age' feature to track lap time performance across individual race stints. It compares a baseline Linear Regression model against a Random Forest Regressor to visually and quantitatively demonstrate how tire degradation impacts a driver's pace over time.
